使用教程

开始一次检查

  1. 在嘉立创 EDA 专业版中打开目标 PCB，确认已生成最新覆铜。打开「回流路径」菜单，选择「单对点检查」或「多对点检查」。部分客户端将扩展入口放在「高级」菜单下。
  2. 按工作区域顶部的提示，先点击起始点，再点击流入点。两端可选择有网络的铜层焊盘、金属化多层焊盘、通孔过孔或走线。焊盘和过孔以中心取点，走线取点击位置在中心线上的投影。
  3. 两端应属于相同的非空网络，并位于同一个闭合板框内。落在边界、槽孔或不同板框上的点会触发提示。盲埋孔和非金属化多层焊盘可能因缺少可靠连接信息而无法作为换层端点。
  4. 单对检查在选点完成后自动计算。需要更换参数或重复检查时，点击「计算 / 重新计算」。顶部会显示选点或计算进度，选点和计算期间可按 Esc，或点击顶部提示条的取消按钮结束本次操作。

采集多对点与选择计算方式

点击「采集下一对点」，依次选择起始点 A、流入点 A，再采集 B、C 等，最多可采集 8 对。每行右侧的下拉框可指定该起始点对应的流入点，重复配对会自动交换对应关系。

在「配置 → 计算方式」中选择「分开计算」，可分别查看每对端点的路线。选择「共同计算」会把各对的板内路线组合，按总长度排序。多块板可以位于同一个 PCB 文件中，每一对的两端仍需位于同一个闭合板框内。

查看列表与切换单位

列表按路线长度从短到长排列，默认选中第一条，每页显示 50 条。点击其他路线后，工作区与示意图会同步更新。同页选择会保留列表滚动位置，翻页可查看更多路线。

点击列表标题右侧的「mm / mil」切换长度单位，当前单位会加粗显示。路线总长度、共同组合中各点对的长度和路线步骤长度都会同步切换。1 mil 等于 0.0254 mm。板厚、铜层深度和线宽配置以输入框旁标注的单位为准。

列表下方的步骤说明显示路线依次经过的铜层、走线、铜区和换层位置。总长度包含同层几何距离，以及已配置的进出铜层之间的换层距离。

操作路径示意图

选择路线后，可使用窗口右上角标题栏的折叠按钮临时收起窗口，在 PCB 工作区查看当前路线。通过折叠后的标题栏可恢复窗口，继续选择其他路线。

  • 滚动鼠标滚轮，以指针所在位置为中心放大或缩小。
  • 按住鼠标右键并拖动，平移示意图。松开右键结束移动，点击「适合窗口」恢复全图。
  • 点击「显示全部路径」叠加已生成的预览路线。选中路线使用配置中的颜色和线宽，其他路线以灰色 0.8 mil 显示。
  • 在叠加模式下点击灰色路线或换层圆圈，可选中对应路线，列表会定位到相应页面。多条路线完全重合的部分优先命中当前选中路线，可在各自分开的路段点击。
  • 点击「仅显示选中路径」可回到单条预览。更新工作区时，标题栏会显示「更新预览…」。大量路线达到画布预览容量时，其余路线可在列表中逐条选择查看。

图层显示、颜色与线宽

在「配置 → 图层显示」选择「跟随画布」「仅当前铜层」或「全部铜层」。「仅当前铜层」还可以手动指定铜层。在弹窗中按 Shift+S 可切换当前层显示，工作区的原生单层显示状态也会影响跟随模式。

在「配置 → 路径样式」选择按铜层配色、逐层自定义或统一颜色。逐层选择铜层后，可修改该层的颜色和示意图基础线宽，默认基础线宽为 3.5 mil。工作区线宽默认 8 mil，可在 0.2–50 mil 范围内设置。

「曲线线段密度」提供 1× 至 4×。提高密度会增加圆滑预览的线段数。圆角预览即时更新，原生圆弧采样需要重新计算后更新。圆角受实际铜区边界约束。

设置过孔与换层长度

在「配置 → 过孔与换层长度」查看当前距离来源及铜层间距。扩展优先使用可读取的物理叠层数据。缺少完整叠层时，可填写备用板厚并点击「按板厚估算」，或输入各铜层中心相对顶层中心的深度后点击「保存手动深度」。

顶层深度为 0，各层深度应不同且底层最深。换层长度按实际进入和离开的铜层深度差计算。修改参数后点击「计算 / 重新计算」，新长度会参与路线排序。板厚估算值可在拿到实际叠层后调整。

清除预览与导出调试日志

生成的线条位于独立的非铜自定义层「回流路径预览」。点击「清除已生成路径」可删除扩展记录的预览图元。重新计算会先清理上次预览。「关闭预览」会关闭结果窗口，已写入的非铜线条可继续通过该层查看。

点击「导出调试日志」后，在日志弹窗选择「保存 .log 文件」。也可点击「选中文本」后复制。日志包含选点、网络、坐标、板框及叠层校验、铜箔建模、正向与反向搜索、同层搜索和预览操作。关闭结果窗口或取消检查时会清空会话日志，已导出的文件可用于反馈问题。

「回流路径 → 查看运行日志」可打开 EDA 原生日志面板，带有「[回流路径]」前缀的条目会记录计算和异常信息。

理解结果与常见提示

扩展会尝试不同出发方向、沿途岔口、反向搜索及可用的全程同层路线，并合并相似走法。结果表示在已读取铜箔中的几何连通路线。实际电流分布、回流阻抗和高频耦合还需要电气模型。

  • 提示网络不同或板框校验失败时，检查端点网络、所属板框和槽孔位置，再重新采集或修复板框。
  • 提示未找到路线时，确认已重建覆铜，检查网络是否真实连通，并查看是否存在图元读取或建模限制。
  • 提示达到搜索预算或部分铜箔未完成建模时，列表显示本次确认的候选路线。可导出日志，将端点位置、出现提示的操作和日志一起用于排查。

版本为 **1.0.0**，发布日期为 **2026-11-11**。发布内容包括扩展包、SHA-256 校验文件、中文更新说明，以及公开仓库内的源码和图文使用说明。

## 验证方法

- 本地验证通过 55 项 Node.js 功能回归与 5 项 Python 打包测试。
- Node.js 自动回归覆盖几何求解、界面事件及模拟的 EDA 操作入口。
- Python 自动验证覆盖安装包内容、Logo、校验值、重复构建、构建失败后的文件完整性，以及 Windows 默认编码下的命令行校验。
- 独立浏览器渲染当前界面与示例路线，用于检查布局、单位切换及教程弹窗，生成 README 截图。
- GitHub Actions 在 Windows 环境执行相同测试，成功后发布安装包和校验文件。

源码、构建过程和图标资源均可通过公开仓库检查。下载后可执行以下命令比对 Release 中的校验值。

```powershell
Get-FileHash .\return-path-inspector_v1.0.0.eext -Algorithm SHA256
```

## 实际客户端验证范围

1.0 的自动回归使用 EDA V4.1 风格接口数据。当前发布过程使用独立浏览器验证界面，实际 EDA 客户端内的 1.0 安装升级、图标显示、原生折叠按钮及真实 PCB 操作尚待人工回归。

如反馈客户端问题，请提供 EDA 版本、所用铜层、端点网络、复现步骤和导出的调试日志。

## 支持范围与已知限制

- 在可读取的同网络铜箔中查找不同的几何可行路线，采用候选搜索与相似路线合并。
- 复杂铺铜、多接点、图元解析和预算仍可能影响覆盖率，界面会显示检测到的建模或搜索限制。
- 过孔与通孔焊盘的换层长度使用物理叠层、手动深度或板厚估算，估算来源会在界面中显示。
- 实际电流密度、回流阻抗、高频耦合与制造偏差需要相应电气模型和工程验证。
- 预览保存在专用非铜层，保存 PCB 时可随设计保留。可通过扩展清理记录的预览线。

完整操作方法与图文示例见 [README](../README.md)，详细几何判定见 [使用指南](guide.md)。

# 使用指南

适用目标为 Windows 上的嘉立创 EDA 专业版 V4.1。扩展包内含脚本和列表界面。导入扩展包后可以直接使用。

## 导入和使用

1. 打开一个测试 PCB 或工程副本。在 **高级 → 扩展管理器 → 导入** 选择 `return-path-inspector_v0.1.35.eext`。在已安装列表启用扩展，新版扩展内置项目 PNG 图标。顶部没有独立的“回流路径”菜单时，在“高级”菜单下找扩展入口。扩展可在「允许外部交互」关闭时使用。
2. **单对点检查**。先单击电流起始点，再单击流入点。两端都可以选择有网络的铜层焊盘、金属化多层焊盘、通孔过孔或走线。焊盘和过孔以中心取点，走线取点击位置在中心线上的投影。当编辑器先命中铺铜、走线或整个器件时，扩展会用光标位置寻找覆盖该点的可见层焊盘。命中多个焊盘时，可放大后点焊盘中心或只显示目标铜层。盲埋孔与非金属化多层焊盘会提示原因。
3. **多对点检查**。打开窗口后，点击“采集下一对点”，按提示依次采集起始点 A、流入点 A，再采集 B、C 等。每个起始点右侧可选择对应的流入点。修改对应关系时会交换冲突的流入点，保持一对一。
4. 在 **配置 → 计算方式** 选择模式。**分开计算**可在列表上方选择点对，并按该对的路线长度排序。**共同计算**将所选配对的板内路线组合，按各对长度之和排序，翻页时按需生成该页组合。不同点对可处于不同闭合板框。每一对都必须在一个板框内通过校验。每页 50 条，翻页时会选中该页第一条。
5. 列表默认选中第一条路线，点击同页其他行会保留滚动位置。点击「显示全部路径」后，可在示意图直接点击灰线或换层圆圈，列表会翻到对应页并选中路线。滚轮以鼠标位置为中心缩放，按住右键拖动可平移，「适合窗口」恢复全图。更新预览时标题栏会显示加载提示。画布标记与示意图使用相同的预览坐标，未选中路线以灰色 0.8 mil 显示。叠加达到预览预算时，可在列表逐条查看其余路线。
6. 在 **配置 → 图层显示** 可以选择“跟随画布”“仅当前铜层”或“全部铜层”。主画布按 Shift+S 切到隐藏其他层时，“跟随画布”根据可见图层过滤。仅置灰时仍显示可见铜层。也可在“仅当前铜层”中手动指定铜层。弹窗接收到 Shift+S 时会切换显示模式。
7. 在 **配置 → 路径样式** 中，**工作区线宽**默认 8 mil，可设为 0.2–50 mil。示意图仍可逐层设置基础线宽，默认 3.5。配色可选择“按铜层配色”“逐层自定义”或“统一颜色”。**曲线线段密度**可选 1× 至 4×，默认 2×。两处的预览圆角会即时更新，原生圆弧采样在重新计算后更新。设置按 PCB 在本机保存。
8. “回流路径预览”是独立的非铜自定义层，随选择和显示范围更新。关闭弹窗后，可在该层查看统一层色的线条。
9. 在菜单或弹窗点击“清除已生成路径”。重新计算会清除上次生成的路径。板框校验排除已登记的预览图元，并按 ID 重读板框折线，防止 EDA V4.1.93 的批量查询把预览折线坐标错配给板框。如果板框几何校验失败且存在旧预览，扩展会先清除已登记的预览图元，再重新读取板框一次。清除按 PCB 文档和已记录的图元 ID 定位，空的预览层可复用。
10. **回流路径 → 查看运行日志**会打开 EDA 底部的原生日志面板。找带 `[回流路径]` 前缀的条目，可以查看选点类型、网络和铜层、校验结果、可行解数量、长度范围、计算耗时及异常信息。
11. 在结果弹窗点击 **导出调试日志 → 保存 .log 文件**，计算中也可取当前快照。客户端限制下载时，可点击「选中文本」并按 Ctrl+C。日志包括 PCB 选点和操作、板框及叠层、网络图元计数、求解阶段、过孔合并、预算、预览和异常堆栈。会话最多保留 1,000 条，并受文本大小预算限制。关闭结果弹窗或取消检查时清空会话日志，手动导出的副本可以留作调试。
12. 点击列表标题右侧的 **mm / mil** 切换列表及路线步骤中的长度单位。点击工具栏最右侧的 **使用教程** 可打开内置详细说明，按 Esc 或点击「关闭教程」返回结果界面。
13. 选中路线后，点击窗口标题栏右上角的 **折叠按钮** 临时收起窗口，即可在 PCB 工作区预览当前路线。通过折叠后的标题栏恢复窗口，可继续选择路线。

点击单对点或多对点检查后，编辑器视口顶部居中的提示条会持续显示选点指引。进入计算后，提示条显示计算阶段、当前点对和进度条，计算完成或出错时自动收起。提示条中显示灰色的「按 Esc 取消」。若画布获得焦点时 EDA 未把 Esc 传给扩展，可点击「取消」按钮。

展开 **配置 → 过孔与换层长度** 可查看叠层来源及每对相邻铜层的间距。扩展优先读取图层管理器中的物理叠层（[官方接口](https://prodocs.lceda.cn/cn/api/reference/pro-api.pcb_layer.getcurrentphysicalstackingconfiguration.html)自 V4.2 提供）。读取不到完整物理叠层时，可手动输入每个铜层中心距顶层中心的深度，或填写板厚让扩展估算。备用板厚默认 1.6 mm，按当前 PCB 的铜层数分配：双层板采用单段，四层板按[嘉立创 JLC04161H-7628 参考叠层](https://jlcpcb.com/impedance)的间距比例缩放（1.6 mm 时顶层到内层 1 约为 0.243 mm），其他层数采用等间距估算。保存后点击 **计算 / 重新计算**。备用板厚和手动深度按 PCB 保存。

## 判定与范围

- **硬校验**。起始点和流入点需要有相同的非空网络名，并且处于同一个可确定的闭合板框内。分开的外框、边界、槽孔和开口板框都会触发校验。共同计算中任一对未通过校验，该次共同计算即停止。分开计算中错误对单独列出。
- **路径长度**。沿铜层计算几何长度，过孔和金属化通孔焊盘的换层距离也计入总长及排序。换层距离是进出铜层沿板厚方向的中心深度差。将多层焊盘或过孔选为起点或流入点时，允许从其任一相连铜层起算或结束。孔径用于几何接触判定。电流分布、回流阻抗与高频耦合需要电气模型。
- **图模型**。识别同层走线交点、普通过孔、金属化通孔焊盘、实心填充、热焊盘辐条与可读取的泪滴。实心覆铜按实际填充边界划分为连通单元，搜索焊盘、过孔和开口之间不同的绕行路线。复杂覆铜的几何最短长度是候选近似值。复杂焊盘接触、盲埋孔、网格覆铜和无法解析的内电层也可能漏算。界面会报告检测到的限制。
- **铜区几何**。候选按通道开口依次拉直，并校验每段中心线是否仍在铜区和板框内。必要时回退到经过验证的通道中线并尝试倒角。重复使用相同铜区通道的候选共用该通道的求解结果。
- **近邻过孔**。孔中心距离不超过 0.5 mm，实际接入的铜层和对应铜区相同，每层都能直连或经短绕行相连，且各层孔间距离差不超过 0.025 mm 时，合并为一个换层分支。短绕行长度上限为孔间直线距离的 1.5 倍。代表孔按到起始点和流入点的直线距离之和近似选取，相同则选靠近起始点的孔。选作端点的过孔和金属化焊盘单独处理。
- **代表路线**。加权迷宫沿已验证的铜箔通道搜索无环走法。找到首条路线后，先按起始铜层和离开方向试走起点的其他出口，再交替探测起点的剩余出口与沿途岔口。相同换层顺序和孔位的候选按各段同层的实际走向比较。几何近似且中间没有被槽孔或铜区开口隔开时，保留已找到的最短候选。调试日志分别记录起点和沿途的探测次数、发现的独立解数量，以及前几条代表路线的孔位。
- **反向与同层搜索**。正向结束后交换起点与流入点补搜。反向路线统一转回原顺序，两端有共同铜层时再专门搜索全程同层的路线，搜索中禁止通过过孔或多层焊盘换层。各轮共用结果，日志分别记录新增与重复路线数。
- **搜索预算**。最多 8 对点。连接图、每轮搜索时间及迷宫状态使用独立预算。达到预算时会提示覆盖可能不完整。单对路线和共同组合均按长度分页，画布叠加使用独立的预览预算。
- **取消与内存**。按 Esc 或点击取消会终止当前求解，释放本次模型、路径和预览缓存，清理本次新建的预览。已经发出的 EDA 数据读取请求返回后会丢弃其结果。
- **保存范围**。若保存 PCB，预览层图元也会作为非铜图元随设计保存。归档或出生产资料前可用扩展清除。清除记录保存在扩展的用户配置中。在另一台电脑或移除扩展后，可在确认图层内容后于 EDA 中自行清理专用层。
- **临时标记**。EDA 的标记清除接口按标签页作用，同一标签页由其他工具建立的临时指示标记也可能被清除。
